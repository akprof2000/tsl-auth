Как вызвать

Каждый запрос к защищённому методу несёт access-токен TSL Auth в заголовке Authorization: Bearer <токен>. Токен пользователя приложение получает при входе (authorization code + PKCE), сервис — сам: POST <TSL Auth>/connect/token с grant_type=client_credentials. Права — разрешения матрицы доступа (claim permissions): без нужного разрешения метод отвечает 403, без токена или с чужим — 401.
